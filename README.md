# Drafta releases

Signed builds of [Drafta](https://drafta.org), a Markdown note-taking app for macOS.

Download the latest `Drafta-<version>.dmg` from [Releases](https://github.com/rpegorov/drafta-releases/releases/latest).

Builds are signed with the "Drafta Self-Signed" certificate and are not notarized. On first launch macOS blocks the app: open **System Settings → Privacy & Security** and click **Open Anyway** once. After that, updates arrive in the app through Sparkle and are verified with an EdDSA signature.
